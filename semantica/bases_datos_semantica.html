Concepto y Tipos de bases de datos

Bases de datos relacionales (RDBMS)

Las bases de datos relacionales organizan la informacion en tablas compuestas por filas(registros) y columnas (campos). Se basan en el modelo relacional y utilizan el lenguaje SQL para realizar consultas y gestionar los datos de manera estructurada.


Ejemplos de sistemas gestores relacionales populares son mySQL, PstgreSQL y Oracle.

Bases de datos No Relacionales (NoSQL)

Las bases de datos NoSQL estan diseñadas para gestionar grandes volumenes de datos no estructurados o semiestructurados. A diferencia de las relacionales, no requieren de esquema rigido y permiten escalabilidad horizontal


Existen distintos tipos segun el modelo de almacenamiento: Orientadas a documentos, clave-valor, columnas o grafos. Un ejemplo representativo es MongoDB.

Estructura de una base de datos relacional

Componentes fundamentales

Para definir la estructura de un modelo relacional se emplean los siguientes elementos:

  • Tablas (Entidades): Estructuras donde se organizan los datos.
  • Campos (Atributos): Columnas que definen la tipología de información.
  • Registros (Tuplas): Filas que contienen cada instancia concreta de datos.
  • Claves primarias (Primary Keys): Identificadores únicos de cada registro

Relaciones entre tablas

Cardinalidades y claves foraneas

Las relaciones determinan como se vinculan las entidades entre si según las reglas de negocio del sistema:

  • Relacion 1:1 (Uno a uno)
  • Relacion 1:N (Uno a muchos)
  • Relacion N:M (Muchos a Muchos)

Las Claves foráneas desempeñan la función de vincular dos tablas mediante un identificador que vincula un dato de una tabla con otra

Glosario de terminos

  • SQL: Un lenguaje de programación estándar diseñado para gestion de bases de datos
  • SGBD: Sistema de gestion de bases de datos
  • Normalización: es un proceso de diseño de bases de datos relacionales que organiza los datos en tablas estructuradas para eliminar la redundancia y mejorar la integridad de los datos.
