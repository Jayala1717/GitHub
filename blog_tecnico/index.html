El Incidente de Php

Por Juan ayala|27/10/2026

Que ocurrió?

Dos vulnerabilidades críticas de seguridad, conocidas como PHP2Shell (CVE-2026-109618 y CVE-2026-109619), fueron descubiertas en el lenguaje de programación PHP en octubre de 2026, afectando a más del 70% de los sitios web de internet. Estos fallos permitían la ejecución remota de código sin autenticación, lo que habilitaba a los atacantes para tomar el control total de los servidores y robar datos confidenciales.

Como se solucionó?

La Fundación PHP publicó parches de emergencia (versiones 8.5.12, 8.4.27, 8.3.36 y 8.2.35) el 21 de octubre de 2026 para corregir los errores de gestión de memoria y limpieza de peticiones que causaban las vulnerabilidades.

Kubernetes

29/10/2026 | Por JuanA

Que es?

Kubernetes (K8s) es una plataforma de código abierto para la orquestación de contenedores que automatiza el despliegue, escalado y gestión de aplicaciones distribuidas. Fue creada por Google.

Para que se creo?

Se diseñó para resolver la complejidad de gestionar miles de contenedores en producción, eliminando la necesidad de operaciones manuales mediante:
Automatización: Gestión automática del ciclo de vida de los contenedores.
Escalabilidad: Capacidad de crecer sin aumentar el equipo de operaciones.
Portabilidad: Funciona de manera consistente en entornos locales, híbridos y de nube pública. Resiliencia: Garantiza la disponibilidad de las aplicaciones mediante la tolerancia a fallos.

Copias de seguridad y buenas practicas

29/20/2026|Por Juan A

Que son las copias de seguridad?

Una copia de seguridad (o backup) es el proceso de duplicar la información de un dispositivo en un soporte secundario independiente, con el fin de poder recuperar los datos en caso de pérdida, daño, eliminación accidental o ciberataques.

Cual es una buena practica para hacer copias de seguridad?

Implementar una estrategia de copias de seguridad eficaz se basa en la regla 3-2-1:
Mantener 3 copias de los datos, en 2 tipos de soportes diferentes (ej. local y nube), con 1 copia almacenada fuera de las instalaciones. Para garantizar la integridad, es fundamental automatizar los procesos, cifrar la información (especialmente en la nube) y realizar pruebas periódicas de restauración para asegurar que los datos son recuperables.
